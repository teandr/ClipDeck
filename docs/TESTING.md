# Проверка ClipDeck на Mac

## Статус

Приведённые ниже пункты — **план проверки и ожидаемые результаты**, а не отметки о пройденных испытаниях. В среде подготовки проекта отсутствуют macOS SDK и графическая сессия macOS. Результат сборки, проверки подписи, системных разрешений и поведения реальных приложений должен быть записан после выполнения на Mac.

## Автоматические проверки

Из корневой папки проекта:

```bash
xcrun swift --version
xcrun swift test --filter ClipDeckCoreTests
bash scripts/build.sh --zip
codesign --verify --strict --verbose=2 dist/ClipDeck.app
```

Тесты ядра проверяют смену режимов, первый и повторный вызов, ожидание завершения копирования, выбор ячейки, отмену, устаревшие callbacks и обработку пустого буфера. Они не проверяют доступность разрешений и реакцию стороннего приложения на реальные события клавиатуры.

Для проверки синтаксиса сценариев без их исполнения:

```bash
bash -n scripts/build.sh
bash -n build.command
bash -n install.command
```

Workflow `.github/workflows/macos.yml` запускает тесты и сборку на Mac. Успешный workflow подтверждает компиляцию, тесты ядра и упаковку; полноценная проверка работы в интерфейсе остаётся отдельным этапом.

## Подготовка ручной проверки

Запишите модель Mac, архитектуру, версию macOS, версию Swift и список других утилит, использующих буфер обмена. Для первого прохода закройте другие менеджеры сочетаний ⌘C/⌘V. Используйте несекретный текст и временные файлы.

Установите ClipDeck в `~/Applications`, разрешите «Универсальный доступ», оставьте исходную настройку количества на 10, откройте TextEdit и создайте два новых документа. Во втором документе установите курсор в пустую строку. Для проверки RTF включите форматированный текст.

## Копирование и вставка

| Сценарий | Шаги | Ожидаемый результат |
| --- | --- | --- |
| Первый вызов копирования | Выделить `alpha`, нажать ⌘C один раз. | Появляются «Система» и 10 номерных ячеек; приложение-источник остаётся активным. |
| Выбор мышью | Щёлкнуть ячейку 2. | Панель закрывается; в ячейке 2 сохранён `alpha`. |
| Выбор цифрой | Скопировать `beta`, нажать 3. | `beta` сохраняется в 3; цифра не попадает в документ. |
| Десятая ячейка | Скопировать `ten`, нажать 0. | Заполняется ячейка 10. |
| Повторное копирование | Выделить `default`, дважды отдельно нажать ⌘C. | Заполняется ячейка по умолчанию; панель закрыта. |
| Первый вызов вставки | В пустом документе нажать ⌘V один раз. | Показан выбор; в документ пока ничего не вставлено. |
| Вставка выбранного | После ⌘V нажать 2. | Вставлен ровно один `alpha`; панель закрыта. |
| Повторная вставка | Дважды отдельно нажать ⌘V. | Вставлен ровно один `default`. |
| Изменение default | Выбрать ячейку 3 по умолчанию в меню; дважды нажать ⌘V. | Вставлен `beta`. |
| Пустая ячейка | Выбрать незанятую ячейку после ⌘V. | Нет вставки старого системного буфера; панель остаётся с пояснением. |
| Быстрый двойной вызов | Очень быстро дважды нажать ⌘C. | Сохранение произойдёт после получения нового снимка; старый снимок не подставляется. |
| Удержание клавиши | Удерживать C или V при нажатой Command. | Автоповтор не выбирает default и не создаёт многократных вставок. |
| Цифра с Command | После первого вызова выбрать цифру с всё ещё нажатой Command. | Выбрана ячейка, не выполнена команда приложения на эту цифру. |

## Компактная панель и предпросмотр (0.2.0)

| Сценарий | Шаги и ожидаемый результат |
| --- | --- |
| Размер и задержка | На обычном экране панель содержит 11 ячеек по 48 pt, ширина 616 pt. Быстро провести курсором по ячейкам: карточки не мигают. Задержать курсор на одной на 0,5 с: появляется карточка нужного буфера. |
| Длинный текст и фокус | Сохранить многострочный текст с emoji, табуляцией и кириллицей. Навести курсор, затем перейти в карточку и прокрутить колесом и полосой прокрутки. Щелчок внутри карточки не закрывает панель и не меняет активное приложение. Выбор ячейки после просмотра вставляет текст в исходное поле. |
| Разные данные | Проверить пустую ячейку, PNG/TIFF, несколько файлов Finder и неподдерживаемый формат. Для изображения видна миниатюра, для файлов — пути. Список форматов можно прокрутить. В режиме копирования показывается прежнее содержимое ячейки до подтверждения замены. |
| Отмена подготовки | Быстро переходить между занятыми ячейками; нажать Esc во время подготовки изображения. Прежняя карточка не появляется повторно. Проверить также переключение ⌘C/⌘V, выбор цифрой и щелчок вне панели. |
| Неподвижный курсор и экраны | Открыть панель под заранее установленным курсором: предпросмотр появляется после задержки без дополнительного движения. Проверить ячейки 1 и 10 на втором экране и при Dock сбоку: карточка остаётся в доступной области экрана. |
| Ограничения показа | Проверить текст длиннее 20 000 символов и список более 64 файлов. Карточка сообщает о сокращении. Вставка из ячейки сохраняет полный исходный фрагмент, если он укладывается в лимит хранилища. |

## Настройка количества буферов

| Сценарий | Шаги и ожидаемый результат |
| --- | --- |
| Границы и применение | В «Настройках» установить 1, затем 30. После «Применить» панель показывает System + 1 или System + 30, без растянутых квадратов. Проверить поле, стрелки, отмену, пустой ввод, 0, 31 и нечисловой ввод: недопустимое значение не применяется. |
| Сохранение настройки | Установить 7, закрыть и запустить приложение. Сохранены количество 7 и допустимый default; номерные ячейки пусты, системный буфер доступен. |
| Скрытие без потери | При 10 ячейках сохранить `keep` в ячейку 8. Уменьшить до 3, затем увеличить до 10 в том же сеансе. Ячейка 8 снова содержит `keep`. При 3 ячейках нажатие 8 не вставляет скрытый фрагмент. |
| Скрытый default | Назначить ячейку 8 по умолчанию и уменьшить количество до 3. Default становится 1; повторное ⌘C/⌘V использует её. |
| Буферы 11–30 | При 30 ячейках сохранить и вставить фрагмент мышью через ячейку 30. Открыть её предпросмотр и перевести курсор вверх через другие ряды в карточку для прокрутки: исходная карточка сохраняется. Сделать ячейку 30 default и проверить повторное ⌘C/⌘V. Клавиши 1–9/0 продолжают выбирать только первые десять. |
| Перестроение и отмена | Менять количество после копирования или при открытой панели, затем проверить новый выбор. Поздние ответы прежнего копирования не сохраняют содержимое в скрытую ячейку. Проверить все ряды и наведение на 30-ю ячейку. |
| Очистка скрытого | Сохранить в 8-ю ячейку, уменьшить до 3, выполнить «Очистить сохранённые буферы», снова увеличить до 10. Ячейка 8 пуста. |

## Темы оформления (0.3.0)

Для native Liquid Glass выполните сборку через `bash scripts/build.sh` с macOS SDK 26+ и Swift 6.2+. Сценарий передаёт флаг поддержки на основании используемого SDK.

| Сценарий | Шаги и ожидаемый результат |
| --- | --- |
| Пять вариантов | В «Настройках» выбрать и применить каждую тему. Проверить панель, копирование и вставку, пустую/системную ячейку, текстовый и графический предпросмотр, уведомление и справку. Текст, контуры, иконка закрытия и default читаемы на фоне. |
| Apply и Cancel | Сменить тему в списке и нажать «Отмена»: прежняя тема остаётся. Затем применить другую: оформление меняется, существующие сохранённые фрагменты не теряются. Неверное количество блокирует применение обеих настроек. |
| Сохранение | Применить тему, завершить и запустить приложение: выбранное оформление восстановлено. |
| Системное переключение | После принудительно тёмной выбрать «Системная». Переключить macOS между светлым и тёмным режимами при открытой панели и карточке: фон, текст и рамки обновляются без перезапуска. |
| Liquid Glass | На macOS 26 в сборке с SDK 26 выбрать Liquid Glass. Проверить нативную стеклянную поверхность, скругления, несколько рядов, прокрутку, hover и сохранение фокуса исходного приложения. |
| Старый SDK/OS | В сборке со старым SDK и/или на macOS до26 Liquid Glass недоступна, остальные темы работают. Сохранённая glass-настройка использует системную тему без обращения к недоступному классу. |
| Доступность | Проверить светлую и тёмную темы с увеличенным контрастом и уменьшением прозрачности в macOS. Контент остаётся читаемым, выбор ячейки и прокрутка работают. |

## Системная ячейка

| Сценарий | Шаги и ожидаемый результат |
| --- | --- |
| Запуск с уже скопированным фрагментом | До запуска ClipDeck скопировать текст. После запуска нажать ⌘V, навести курсор на «Система» и щёлкнуть её. Видно и вставляется актуальное содержимое; ячейка 1 автоматически не заполняется. |
| Снятие паузы | Сохранить `saved` в ячейку по умолчанию, приостановить ClipDeck, скопировать `system` обычным ⌘C, включить ClipDeck. «Система» показывает и вставляет `system`, прежняя ячейка по умолчанию содержит `saved`. |
| Оставить результат копирования в системе | Нажать ⌘C, затем «Система», в том числе пока копирование ещё идёт. Панель закрывается, номерные ячейки не меняются; поздний callback не сохраняет результат в отменённую ячейку. |
| Изменение при открытой панели | Из тестового источника поменять системный буфер без активации другого окна. Системная ячейка обновляется; новая ревизия с теми же первыми 80 символами тоже обновляет полный предпросмотр. |
| Неподдерживаемые и большие данные | При недоступном предпросмотре выбор «Система» всё равно отправляет обычную вставку. ClipDeck не перезаписывает системный буфер ограниченным снимком. |
| Закрытие и повторное открытие | Закрыть панель во время чтения медленного источника; сменить системный буфер и открыть панель. Старое содержимое не появляется повторно, зависшего индикатора нет. |
| Очистка сохранённых ячеек | Выполнить «Очистить сохранённые буферы». Все номерные ячейки пустые, «Система» продолжает показывать буфер macOS. |

## Отмена и гонки

| Сценарий | Ожидаемый результат |
| --- | --- |
| Esc при копировании | Панель закрывается; сохранённые ячейки не меняются. Обычное копирование в системный буфер уже выполнено. |
| Esc при вставке | Панель закрывается; текст не вставлен. |
| Щелчок вне панели | Выбор отменяется; нажатие мыши сохраняет обычное действие. |
| ⌘Tab при открытой панели | Выбор закрывается; последующая вставка не адресуется старому приложению. |
| Источник завершается до завершения копирования | Старая ячейка не перезаписывается неподтверждённым содержимым. |
| Копирование без выделения/при недоступной команде Copy | После тайм-аута ячейки остаются прежними; есть понятное сообщение. |
| ⌘C, затем ⌘V до завершения копирования | Старый callback копирования не меняет новый режим и не сохраняет данные самовольно. |
| Быстрые Esc, ⌘C, выбор другой ячейки | Завершение отменённой сессии не перезаписывает ячейку новой. |
| Изменение системного буфера во время чтения другим приложением | Не сохраняется смесь форматов из разных ревизий. |
| Смена активного приложения перед отправкой вставки | Вставка отменяется, а не перенаправляется в неожиданное приложение. |

## Форматы и объём

Проверьте обычный текст, длинный текст, текст с emoji и кириллицей, несколько абзацев RTF с форматированием, HTML из Safari, изображение из Preview, один локальный файл и несколько локальных файлов из Finder. После записи каждой ячейки скопируйте что-то другое, затем вернитесь к исходной ячейке и вставьте её: это проверяет наличие собственного снимка, а не ссылки на текущее содержимое буфера.

Для файлов работайте в двух временных каталогах. ClipDeck хранит ссылки; не ожидайте сохранения содержимого удалённого файла. Объекты из Photos, облачных провайдеров и форматы с file promise рассматривайте как отдельные проверки совместимости.

Проверьте превышение лимита 64 MiB на снимок и 256 MiB суммарно. Ожидается отказ от нового сохранения с пояснением и сохранность уже заполненных ячеек. Не используйте рабочие документы для искусственного наполнения памяти.

Снимок с пометкой `org.nspasteboard.ConcealedType` или `org.nspasteboard.TransientType` должен быть отклонён. Для этой проверки используйте тестовое приложение/скрипт с фиктивным содержимым, не реальный пароль.

## Интерфейс и среда

- Один экран и два экрана с разным масштабом; панель целиком помещается в доступную область выбранного экрана.
- Dock снизу и сбоку; квадраты остаются видимыми и кликабельными.
- Светлая и тёмная тема; подписи и номера читаются.
- Полноэкранные Safari/TextEdit и переключение Spaces; панель появляется в правильном пространстве, не переключая приложение.
- Уменьшение прозрачности в настройках универсального доступа; интерфейс сохраняет контраст.
- Отсутствие разрешения Accessibility при первом запуске; обычные ⌘C/⌘V продолжают работать.
- Отзыв разрешения во время работы; нет зависшей блокировки ввода.
- Sleep/wake и блокировка/разблокировка; прежняя незавершённая операция не возобновляется неожиданно.
- Secure Event Input; приложение не пытается обходить защиту.
- Закрытие и повторный запуск; номерные ячейки пустые, количество и default сохраняются, «Система» показывает текущий буфер macOS.
- Установка из каталога, в пути к которому есть пробелы; сборка и установка завершаются корректно.
- Обновление запущенного ClipDeck; приложение завершается обычным способом, новая копия запускается, пользовательские настройки не удаляются.
