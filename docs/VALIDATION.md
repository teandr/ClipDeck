# Статус проверок ClipDeck

- Release-сборка Apple Silicon с macOS SDK 26.4 прошла. Подпись приложения и целостность ZIP проверены.
- Все 53 сценария ядра прошли во временном раннере. Для штатного запуска XCTest используйте полный Xcode.
- На отдельном буфере AppKit проверены восстановление после частичной записи, сохранение более новой ревизии и вставка при незавершённом предпросмотре.

Команды сборки и сценарии проверки клавиатуры, разрешений и интерфейса в реальных приложениях перечислены в [плане проверки на Mac](TESTING.md).
